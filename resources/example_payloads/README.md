# Example Payloads

This folder contains minimal example JavaScript payloads used for quick testing:
`BST_payload.js` and `HUT_payload.js`.

These payloads are designed to be simple and easy to analyze, making them suitable for educational purposes and initial testing of the analyzers implemented in this repository.

They do not work in real-world scenarios but serve as a starting point for understanding how do they work and hide malicious code.

## Disclaimer

These example payloads are provided for educational and testing purposes only. They should not be used in any malicious or unauthorized manner. The authors of this repository do not endorse or condone the use of these payloads for harmful activities. Use them responsibly and ethically.
