# RATatouille payload artifacts

To understand the context and details of the RATatouille attack, please refer to the interesting [RATatouille attack story](https://www.aikido.dev/blog/catching-a-rat-remote-access-trojian-rand-user-agent-supply-chain-compromise).

**Important**: these JavaScript files are published strictly for research, education, and defensive study. The authors and maintainers of this repository categorically dissociate themselves from any malicious use of the code contained here. The code was collected and reproduced as part of a security study into source-level attack techniques and obfuscation; it is not provided as a tool for attacking systems.

## Contents
- `ratatouille_payload.js` — the deobfuscated / human-readable version of the payload.
- `ratatouille_payload_obfuscated.js` — the obfuscated/minified version used from attackers.
